How a version update moves

A push to main starts the pipeline.

01 / VERIFY

Test and build

Ruff, pytest, and a container health check run first.

02 / PACKAGE

Publish image

The checked release is tagged by its Git commit ID.

03 / PREPARE

Check standby

EC2 starts the new version in the inactive color and checks health.

04 / ROUTE

Switch traffic

Nginx changes traffic only after the new slot passes validation.
